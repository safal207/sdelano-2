# ADR-001 — самостоятельная коммерческая ветка

Статус: принято 23.11.2026.

Стабильная «Сделано 1.0» используется людьми и предназначена для QA-портфолио. **Не модифицировать** репозиторий safal207/todo-list/main. Не переносить в него кнопки версии 2.0.

«Сделано 2.0» развивается в отдельном репозитории safal207/sdelano-2. По разрешению владельца этот репозиторий **публичный**: размещаемый исходный код открыт для просмотра, но GitHub Pages и приложение НЕ публикуются. Прямые коммиты в рабочий runtime main и merge — только после отдельного решения владельца. Исходная игровая сборка закреплена по commit SHA dea287e805cb62821fe25075786eee411c7d1546, без связи с экспериментальным переключателем PR #51.

Все задачи и экономика в другом origin **не синхронизируются** автоматически с 1.0. Никакой скрытой миграции; перенос только через подтверждённый пользователем экспорт/импорт либо безопасный сервер.

Релизные ворота: зелёный CI Chromium/Firefox/WebKit, физический Android QA (уведомления отдельно), корректное резервное копирование, проверка домена/безопасности, явное разрешение на deploy и merge.
