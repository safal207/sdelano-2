Отдельная линия разработки игрового планировщика **«Сделано 2.0»** и будущего переносимого ядра **BitOS Game Engine**.

**Внимание:** репозиторий публичный — исходный код доступен всем. Приложение не опубликовано и не готово к коммерческой эксплуатации. Пользовательские данные сюда не переносились.

- **Стабильная 1.0:** [safal207/todo-list](https://github.com/safal207/todo-list) — остаётся нетронутой для пользователей и QA-портфолио.
- **Игровой прототип 2.0:** исходный коммит `dea287e805cb62821fe25075786eee411c7d1546` из Draft PR #50; исходный [CI 3/3 PASS](https://github.com/safal207/todo-list/actions/runs/45136182680).
- **Импорт:** отдельная ветка `import/game-v2-2026-11-23`, а не прямое изменение `main`. Изображения и тесты переносятся через GitHub Actions без текстового перекодирования.
- **BitOS Engine:** отдельный проектный контракт и лабораторные тесты, не подключённые к пользовательскому runtime до отдельной проверки.
- **Публикация:** GitHub Pages, релиз, облачная синхронизация, Telegram Mini App и платежи не включены.

## Принципы

Персонаж отражает **реальные полезные действия**, а не требует внимания. Никаких автономных просьб, наказаний за отсутствие, повторной выдачи наград или игровых обязательств.

Не мержить черновую ветку в `main` и не публиковать приложение без отдельного разрешения владельца.

## Локальный запуск перенесённой версии

Это независимая игровая 2.0 в отдельной ветке. Исходная 1.0 не изменялась.
Запуск: python3 -m http.server 8765 --bind 127.0.0.1.
QA: npm install --no-save --no-package-lock playwright@1.62.1,
затем npx playwright install chromium, затем node tests/game-preview.mjs,
node tests/focus-clock-e2e.mjs и node --test tests/engine-contract.test.mjs.
